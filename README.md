# Product Skills

Agent skills for finding, shaping, building and running products. They accompany the book *The Idea Nobody Wanted*.

Each skill is a plain written file that tells an AI agent how to do one job. Read them, change them and keep them.

| Stage | Skill | What it does |
|---|---|---|
| Gather | `market-analysis` | Turns the business plan and market research into a one-page view |
| Gather | `customer-evidence` | Collects, cleans, codes and ranks customer feedback |
| Gather | `metrics-and-wbr` | Behavioural analytics and a Weekly Business Review pack |
| Shape | `maxdiff-study` | Designs and analyses a MaxDiff and Kano study |
| Shape | `pricing-study` | Designs and analyses a pricing study |
| Shape | `prioritise-roadmap` | Builds a RICE+ table and a prioritised roadmap |
| Approve | `bar-raiser-review` | Reads your work as though every sentence is wrong until proven right |
| Build | `working-backwards` | Drafts a PR/FAQ |
| Build | `usability-test` | Plans and reports usability tests |
| Build | `demand-test` | Tests demand before you build |
| Build | `experiment-design` | Sample sizes, checks and readouts for experiments |
| Run | `post-launch-review` | Reviews a launch and writes the post-mortem |
| Run | `governance-cadence` | Squads, weekly updates and decision roles |
| Lead | `team-design-hiring` | Team design, the 90-day plan and hiring kit |
| Lead | `award-entry` | Builds the evidence pack for an award entry |

## Install

Copy each folder in `skills/` into `~/.claude/skills/`. The scripts need Python and numpy.

For building with agents, see [Desk Skills](https://github.com/bigbenjoman/desk-skills), which take a ticket to a merged pull request.
