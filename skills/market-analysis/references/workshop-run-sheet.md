# Ideation workshop run sheet (2 hours)

| Time | Block | What happens | Output |
|---|---|---|---|
| 0:00 | Frame (10 min) | Goal, the one metric we're trying to move, the rules (no solutions yet) | Shared goal |
| 0:10 | Evidence wall (20 min) | Silent read: top 5 customer problems with verbatims, benchmark gaps, metric opportunities | Everyone has read the same facts |
| 0:30 | How might we (15 min) | Turn each problem into "How might we…?" questions. Vote for the 4 best | 4 HMW questions |
| 0:45 | Silent ideas (20 min) | 4 minutes per HMW, one idea per sticky, no talking | 60–120 stickies |
| 1:05 | Cluster (15 min) | Group duplicates and name each cluster | 10–20 ideas |
| 1:20 | Dot vote (10 min) | 3 dots each; the decision-maker votes last | Ranked list |
| 1:30 | Quick sizing (20 min) | For the top 8: metric moved, rough reach, rough effort (S/M/L) | Inputs for RICE+ |
| 1:50 | Close (10 min) | Owner per idea; next step is a one-page PR/FAQ for the top 3 | Actions |

Materials: evidence pack printed or on screen, stickies, a timer. Remote: a whiteboard tool, with cameras on for the silent blocks.
